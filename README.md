# NATA International Church Network

A global network and resource center equipping Reformed churches to serve and plant faithful churches among the nations.

## Included
- Responsive landing page
- Searchable/filterable resource library
- Resource detail modal for each starter topic
- Church leadership pathway
- Multilingual interface selector
- Contribution/request form UI
- Mobile navigation
- No build system or paid platform required

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy free
Upload the `nata-international-church-network` folder to GitHub Pages, Netlify, Cloudflare Pages, or another static host.

## Before public launch
1. Replace the starter content with reviewed theological resources.
2. Add your actual ministry contact/form endpoint.
3. Add translated resource files as they are reviewed.
4. Add your domain and favicon/social metadata.
